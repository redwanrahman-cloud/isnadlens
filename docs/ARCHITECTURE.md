## Ordinary claims and combined source search
Auto identifies direct quotations where possible; safe ordinary claims and general Islamic source questions instead search both admitted source families. Exact source matches bypass search planning. The API infers unambiguous Arabic/Latin script to correct stale input-language selections; the original input is stored unchanged.

After scope/privacy, attribution, explicit citation and source-admission gates, a separately budgeted AI planner returns bounded Arabic/English search hints. Digits, locators, URLs, instructions and malformed terms are rejected. Search hints are never evidence. Quran/Hadith quotations are retrieved from immutable admitted data and individually checked; a combined manifest retains both component manifests/hashes, and at most four cards per family are assessed. Generic propositions may be supported by either family; explicit source attribution must be preserved. Unrelated candidates do not become additional user assertions.

The sealed retrieval_plan distinguishes real planned search, server-provided hints and lexical fallback, and includes planner usage independently from assessment usage. The browser sends no search overrides or trusted source metadata. Unknown provider usage retains conservative spending reservations; there is no automatic network retry. A bounded search does not cover every Islamic source or establish religious completeness.
