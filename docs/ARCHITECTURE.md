# Event-window architecture

Created after Redwan authorized the build on 4 October 2026.

Claim intake → deterministic scope/privacy boundary → frozen admitted-corpus lexical retrieval → exact source/locator/quotation/hash checks → authorized structured semantic assessment → rule-constrained corpus-bounded verdict → sealed record → presentation.

Source quotations remain immutable and Arabic. Search uses the separate official Simple Clean edition; user-query variants do not rewrite stored source strings. Source admission, citation integrity, AI semantic judgment and human review are separate objects.

Fresh verification is unavailable until API access and paid-call authorization are configured. The offline interface may show retrieved authentic passages, but does not claim semantic verification. Synthetic tests are not public religious evidence. No permission has been received for the pilgrimage corpus.

The first increment implements Arabic and English interface views. Four BETA output languages, renderer semantic invariants, durable spend tracking, deployment, independent semantic evaluation, release packaging and optional pilgrimage utilities remain later acceptance gates. None is advertised as complete.

The HTTP route bounds request bytes, caps concurrent work and applies a single-process request limit. A trusted-edge durable limiter and persistent authorized spend budget are required before public operation. No personal claims are written to logs or disk.
