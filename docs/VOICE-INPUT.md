# Voice input

The microphone workflow is record, stop, transcribe, review/edit, then explicitly use the transcript in the claim box. It never starts verification automatically or replaces a typed claim before the user chooses Use this text. Discard cancels pending processing, stops microphone tracks and clears the recording. Recordings stop automatically after 45 seconds; client and server bound audio to 1 MB and transcripts to 1,200 characters without silent truncation.

Google's [dedicated transcription guide](https://ai.google.dev/gemini-api/docs/transcribe) lists Arabic, English, Bengali, Hindi, Urdu, Indonesian, Spanish, French and German locales. Automatic mode detects spoken language; manual selection supplies its supported locale. Transcription is verbatim, with no question-answering prompt, source quotation generation or model verdict. Subsequent source verification retains the same existing privacy/scope/source-integrity gates.

The server uses the already confirmed unpaid Google project; [pricing](https://ai.google.dev/gemini-api/docs/pricing) lists a free tier. Audio is sent only after pressing Transcribe. The visible notice explains that Google receives audio and may use free-service data to improve products; users should avoid private information. IsnadLens does not save uploaded recordings or transcripts in its filesystem or logs. `store:false` is set; this does not override the provider's free-tier data terms. Key access is server-only. Dictation and natural read-aloud share the persistent local cap of two new requests per minute and sixty per UTC day; failed attempts count and there is no automatic retry or paid fallback.

Microphone recording requires user permission, a secure context and browser support for [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) and [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia). WebM/Opus is preferred; MP4/OGG are selected only when the browser reports support. An unavailable/denied microphone or provider leaves typing available. Audio-format signatures are checked server-side, not treated as proof of speech content or speaker identity. The UI recording-duration limit is not a server-side decode-based duration check; public hosting still needs abuse controls.

Live free-tier tests transcribed the existing generated English and Arabic samples correctly, retaining wording and script with normal punctuation differences. These are synthetic, known-text development samples, not live human accent/noise evaluation. Nine locale mappings, input bounds, empty-output handling, unchanged wording and no-retry behavior have mechanical tests. Physical iPhone/Android microphones, accents, noise and nine-language speech accuracy remain unverified.
