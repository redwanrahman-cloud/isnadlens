# Approved visual direction — 5 October 2026

Redwan selected **deep emerald, warm ivory and restrained gold**, reviewed successive mockups and then explicitly approved starting implementation. That approval superseded the earlier evening-phase timing. The approved workspace is now implemented and checked in the local production preview.

## Product journey

- Main workbench: immediate question entry, with Text, Voice and Image choices visible together. The input method is easy to find before scrolling.
- Results: clear answer first, then original source passages, translations and references. Secondary audit details stay expandable. Benchmark presentation leads with 96.7% success in the recorded sample, with exact counts available.
- Saved checks: visible access to historical receipts and reusing a question, plus delete/clear controls.
- Pilgrimage: focused Umrah/Hajj question entry, topic navigation and distinct manual progress controls. No visual design implying that a ritual is certified complete.
- Daily tools: separate easy-to-scan prayer, location, Qibla and calendar areas, with the chosen city/timezone visible.

## Visual character

Use emerald for key navigation, text and primary actions; ivory for the page and reading areas; gold for restrained highlights and thin details. Give the site an Islamic character through subtle geometric lines and arch-inspired shapes, with spacious reading areas and careful Arabic typography. Do not use scripture as decorative background text.

Avoid generic dashboard clutter and excessively ornamental surfaces. Prioritize comfortable Arabic/RTL and Latin/LTR reading, mobile touch targets, keyboard focus, readable contrast and straightforward navigation. Use the existing functioning verification, voice/image and source components underneath the redesign.

The final layout prioritizes verification: compact navigation for Claim Verification and Umrah & Hajj Companion, visible daily-tool links, a clean input panel, assessed answer followed by distinct source cards, and an always-visible evidence map. Additional retrieved passages and detailed audit metadata are expandable. Publisher grades appear only when supplied. Listen controls are attached to content; share-card excerpts and full evidence receipts remain separate exports.

Production checks passed at 1440, 768, 390 and 320 pixels across all nine display languages. Source quotations and assessed summaries remain unchanged. See `artifacts/dashboard-design-2026-10-05.json`. These are presentation checks using frozen responses, not a new semantic accuracy benchmark.
