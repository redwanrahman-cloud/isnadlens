# Fresh fifty: findings and next repair sequence

All 50 new live requests completed with automatic source/language selection on the frozen Luna/Terra low-reasoning build. Developer primary-source review approved 27 principal answers; 23 withheld a conclusion. No opposite decisive verdict was observed. This is inadequate answer coverage, especially for misconceptions: only 4/15 negative propositions received the expected contradiction verdict. Automatic language identification matched 50/50; this does not certify all translations or speech.

These are observable pipeline stages, not proof that each miss has one isolated cause. N25 overlaps retrieval and checking; N28 retrieved a Hadith containing a Quran reference but did not fetch the authenticated Quran verse itself.

## Repairs to prioritize before the next untouched fifty

1. Inspect auto-routing hints and ranking with the exact captured queries. Preserve native meaning and negation. Add general Arabic morphology/synonym handling and bounded recovery retrieval rather than a list of benchmark answers. Avoid arbitrary irrelevant results when no meaningful term matches. Auto selection currently divides eight cards between Quran and Hadith, which can displace the requested source family.
2. When retrieved admitted text refers to another admitted passage, resolve that reference into its authenticated source unit within existing bounds. Never treat an unverified model locator as a source quotation.
3. Repair contradiction qualification handling. A scoped example of women receiving reward disproves a claim that women never receive it; seven/three reversed is directly incompatible with three/seven. Reassess actual text, attribution and conditions instead of changing false flags to true by code.
4. Investigate checker uncertainty on public Arabic questions and translated questions with contextual proof. Keep the checker and integrity barriers. Preserve the original wrong-source rejection control and N25's necessary rejection.
5. Clean generated explanations: N07/N12 contain mixed-language phrases and N13 calls two verses two surahs. Principal grounding is reported separately from editorial correctness.
6. Use these 23 misses as development regressions, retain this frozen 27/50 result, then run a different untouched fifty. A targeted retest is not a revised first-pass score. Discuss this result with Redwan before submitting the second new batch.

## Interpretation of the score

The 35-supported/15-contradicted mix has a 70% always-yes baseline. Observed answer agreement is 54%, with 23 abstentions counted as failures; therefore neither the headline score nor zero wrong decisive labels supports a high-accuracy claim. The always-yes baseline has no grounding requirement and would give 15 wrong decisive answers. Coverage and erroneous decisions must be reported separately.

This set differs from the prior selected-source holdout in topic, language mix and automatic routing; 27/50 versus the prior 44/50 cannot isolate model quality. Sources are present for the reviewed propositions. Most observed gaps concern passage selection, with additional model/guard reasoning failures. A stronger model alone cannot establish a conclusion from an irrelevant packet.

Its principal rejection of generic protection from punishment is supported with worldly-life scope retained; it is not a universal conclusion about every disbeliever or every afterlife circumstance. N49's additional qualification is explicitly attributed to the publisher's supplied explanation, separate from the original Hadith wording.
