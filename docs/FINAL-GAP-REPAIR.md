## Repairs

The server's validated textual admission now reaches both initial and recovery search planning. Personal/private/injection screening still runs. A model's unusable search terms or malformed term schema can lead to the single bounded web discovery attempt; budget, provider, privacy and integrity failures cannot. Client-provided admission flags remain ignored.

The source decision checker now has separate support and contradiction contracts. In decision mode, `entails=yes` confirms the proposed relationship and faithful original proposition; it does not mean the user's assertion is true. A faithfully preserved false proposition with an explicit incompatible source can be confirmed. A silently corrected/reversed atom must still be rejected. Existing immutable unit selection, exact-byte checks, source attribution, qualifiers and final review remain mandatory. The models remain Luna for primary assessment and Terra for contradiction confirmation.

Retrieval now normalizes several ordinary English concept variants in its derived index only, rewards joint original-concept coverage in routed Quran searches, and uses BM25-style document-length normalization for Hadith primary/title matching. There are no answer-key or question-ID lookups in production. Publisher quotations and original input qualifiers remain unchanged. The captured maintenance question's Quran 65:6 rose from rank 14 to rank 3 within the combined-source four-verse allowance. The greeting question's relevant Hadith rose from rank 10 to rank 1.

QuranEnc publisher UI locale is now independent of the application's nine input languages. A verse link in `/fa/` or `/as/` still requires trusted-host checks, exact verse identity and publisher API Arabic-text matching before it can seed an admitted source. This does not admit an unapproved translation as evidence.

Prompt simplification followed [official OpenAI reasoning prompt guidance](https://developers.openai.com/api/docs/guides/reasoning-best-practices#how-to-prompt-reasoning-models-effectively).
